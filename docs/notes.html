Design notes

Designed, not yet running. Everything here is a sample.

Eight choices I made building this desk, why I made each one, and what each one costs.

Fixed steps, not an agent

Filing text can carry a hidden instruction, and with fixed steps it never reaches anything that can act. Each step has fixed inputs, so it can be tested case by case. And models are bad at arithmetic and at remembering rules, so both live in code.

Each seat runs as its own job. Every run ends done, or waiting for me with the reason in the first line.

What it costs. More plumbing. An agent replaces a step only if a test fails because of the single-call shape.

Three model seats, until another earns one

One writes the case, one argues against it, one decides. Each is a separate seat with a separate job, so the writer never grades its own memo. Only the chair runs on Opus.

What it costs. The analyst covers the jobs of three empty roles, which is less independent than separate seats. Whether the risk officer needs Opus is still open.

A veto the chair can’t overrule

The risk officer can veto. A script can turn a pass into a veto, never a veto into a pass. The chair can decline any call but can’t push one past the script’s check, so every path to a published call only gets harder.

What it costs. Good ideas die. A week where nothing clears is a normal week, and it publishes nothing.

The models never see a price

A script turns price into a valuation bucket. A model that never sees a price has nothing to anchor a target on, and its output has no field for sizing, entry or a target anyway.

What it costs. The analyst can’t say a stock looks cheap in dollars. It works from the script’s value range.

Nothing publishes without my signature

I read each call exactly as it would publish. I can approve it, discard it, or lower its confidence, never raise it. Then a script publishes. No seat holds the write key, and silence for 72 hours stops the call.

What it costs. About 37 minutes a week, my estimate, not yet measured. It also caps the desk at 2 decisions a week.

Losses stay up, at full size

Each call is committed with an outside timestamp before its outcome exists. A close is a new entry, and nothing already written is edited. A track record is only worth reading if it can’t be tidied afterward.

What it costs. My mistakes sit on the record for good.

Paper money only, and no sizing

Every call is the same $10,000 of paper money, whatever its confidence. The record can’t flatter itself by betting more on winners, and nothing on it reads as advice.

What I left out. Position sizes, entry zones, stops, price targets and my own holdings, which stay in a private tool that never publishes.

Five roles I chose not to staff

Five more roles could join the three model seats. None has one. Scripts and the analyst cover their work until one earns a seat: two clean runs, its own tests and a written decision. The ceiling is five seats.
